# Presto Foundation (presto-foundation)
The Presto Foundation is a Linux Foundation project supporting Presto, an open source distributed SQL query engine for big data analytics. Founded by Facebook (Meta), Uber, Twitter, and Alibaba, it enables interactive analytics across diverse data sources at massive scale.
